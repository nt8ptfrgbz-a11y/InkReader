# Documentation artwork

All images are referenced with repository-relative paths from the root README files.

| File | Source |
| --- | --- |
| `hero.svg` | Vector banner generated by `scripts/make_readme_assets.py`. |
| `bookshelf.png` | Actual screenshot from an iPhone 17 Pro Max. Cropped by 180 pixels at the top and 48 pixels at the bottom, then resized to a maximum dimension of 1,200 pixels. App content was not retouched. |
| `themes.svg` | Illustrations using the implemented theme colors and text from the bundled novel; not device screenshots. Generated by `scripts/make_readme_assets.py`. |
| `reading-flow.svg` | Diagram of the reading flow. Generated by `scripts/make_readme_assets.py`. |
| `app-icon.png` | Copy of the existing icon from `InkReader/Assets.xcassets/AppIcon.appiconset/`. |

Run `python3 scripts/make_readme_assets.py` from the repository root to regenerate the SVG files. The real-device screenshot is maintained separately.
